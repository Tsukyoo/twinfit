1. Coach Decision Engine
Objectif

Créer le cerveau central de TwinFit.

Problème résolu

Aujourd’hui, les données sont dispersées : sommeil, poids, nutrition, séances, PR, duel. Il faut un moteur unique qui transforme tout ça en décision quotidienne.

Fonctionnement détaillé

Chaque matin, TwinFit calcule un “Daily Decision”.

Inputs :

sommeil d’hier ;
nutrition d’hier ;
eau ;
poids récent ;
séance prévue ;
fatigue musculaire ;
performance des dernières séances ;
progression ou stagnation ;
objectif du profil ;
historique duel.

Sortie :

“Pousser fort aujourd’hui”
“Séance normale”
“Séance technique”
“Repos conseillé”
“Ajouter calories”
“Baisser calories”
“Priorité sommeil”
“Risque de stagnation”
“Bonne journée pour PR”

Exemple :

“Sommeil bon, nutrition respectée, dernière séance réussie : aujourd’hui tu peux tenter +2,5kg sur le rowing.”

Cas spécial :
Si sommeil bas + force en baisse :

“Ne cherche pas un PR aujourd’hui. Garde la charge et valide propre.”

Impact psychologique

L’utilisateur n’a plus à réfléchir. L’app devient un coach qui décide.

Impact business

Très forte rétention : l’utilisateur ouvre l’app pour savoir quoi faire.

Niveau difficulté technique

Complexe.

2. Anti-Stagnation Engine
Objectif

Empêcher la stagnation réelle.

Problème résolu

Les gens arrêtent quand ils ont l’impression de ne plus progresser.

Fonctionnement détaillé

Le moteur surveille chaque exercice.

Détection :

même poids depuis 3 séances ;
reps bloquées ;
RPE haut ;
volume qui baisse ;
sommeil bas ;
nutrition incomplète ;
poids corporel incohérent avec objectif.

Réactions possibles :

“Garde charge, vise +1 rep”
“Monte charge”
“Deload 1 séance”
“Change exercice temporairement”
“Augmente repos”
“Ajoute calories”
“Réduis volume épaules cette semaine”

Exemple :
Développé incliné :

3 séances à 22kg bloqué à 8 reps.
sommeil moyen 5h50.
calories basses.

TwinFit répond :

“Ce n’est pas un problème de force. C’est probablement récupération + énergie. Garde 22kg, dors mieux, ajoute 150 kcal pendant 3 jours.”

Impact psychologique

L’utilisateur comprend pourquoi il bloque. Il ne se décourage pas.

Impact business

Différenciation énorme : peu d’apps expliquent la stagnation correctement.

3. Progressive Overload Autopilot
Objectif

Faire progresser l’utilisateur sans qu’il pense à la prochaine charge.

Problème résolu

La plupart des débutants/intermédiaires ne savent pas quand monter.

Fonctionnement détaillé

Pour chaque série, TwinFit garde :

poids ;
reps ;
RPE ;
douleur ;
qualité ;
temps de repos ;
série concernée.

À la séance suivante :

placeholder = dernière perf de cette série ;
recommandation = objectif précis.

Exemple :
Dernière fois :

S1 35kg x 12
S2 35kg x 12
S3 25kg x 12
S4 20kg x 12

Aujourd’hui :

S1 cible 37,5kg x 8-10
S2 cible 37,5kg x 8-10
S3 cible 27,5kg x 10-12
S4 cible 22,5kg x 10-12

Si RPE absent mais reps hautes validées :

montée légère recommandée avec confiance moyenne.
Impact psychologique

L’utilisateur voit immédiatement “je bats mon ancien moi”.

Impact business

L’app devient utile pendant la séance, pas seulement après.

4. Recovery Readiness Score
Objectif

Savoir si aujourd’hui est un jour pour pousser ou gérer.

Problème résolu

Les utilisateurs forcent quand ils devraient récupérer, ou se sous-entraînent quand ils peuvent progresser.

Fonctionnement détaillé

Score 0-100 basé sur :

sommeil ;
énergie ;
courbatures ;
nutrition ;
eau ;
dernière séance ;
performance récente ;
fréquence d’entraînement.

Sorties :

85-100 : “Push day”
65-84 : “Normal”
45-64 : “Technique”
<45 : “Récupération prioritaire”

Exemple :

“Récupération 42. Ne force pas les jambes. Fais la séance mais garde 2 reps en réserve.”

Impact psychologique

L’utilisateur se sent compris.

Impact business

Augmente la confiance dans l’app.
